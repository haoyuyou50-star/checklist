# 莫奈 · 走进画境 — 高斯泼溅沉浸 Demo

VR 艺术家项目「全景沉浸」模块的 HTML 前期演示。流程：**画作观赏界面 → 点击「进入画境」→ 笔触离开画布、世界向四周展开的转场 → 可交互的 360° 高斯泼溅场景（风吹草浪 / 水波、发光物件、点击拉近） → 离开画境回到展厅**。

当前收录两幅奥赛博物馆藏品：

| | 画作 | 动态 | 可交互物件 |
|---|---|---|---|
| 01 | 《罂粟花田》Coquelicots, 1873 | 草浪、罂粟花瓣随阵风飞起、树冠摇曳、云层呼吸、光尘 | 卡米耶与让、坡顶的树、罂粟花、远处的农舍 |
| 02 | 《阿让特伊的帆船赛》Régates à Argenteuil, c.1872 | 水面波纹与倒影拉伸、帆随风倾、水面闪光 | 白帆、红顶房屋、岸边的树、碎裂的倒影 |

开发者文档：交接说明见 [`HANDOFF.md`](HANDOFF.md)；新增或打磨画作的制作流程、注意点和验收清单见 [`skills/painting-to-gaussian-scene/SKILL.md`](skills/painting-to-gaussian-scene/SKILL.md)。

## 运行

需要通过本地静态服务器打开（ES Module 与读取画作像素都不支持 `file://`，直接双击 `index.html` 会打不开）。

- **Windows**：双击 `start.bat`
- **macOS**：双击 `start.command`（首次若被拦截：右键 → 打开）
- 或手动：

```bash
cd monet-immersive
python3 -m http.server 8123
# 浏览器打开 http://localhost:8123/
```

| 地址参数 | 作用 |
|---|---|
| `?demo` | 自动演示：带虚拟光标，自动走完两幅画的完整流程（约 2 分钟），**适合直接录屏** |
| `?q=high` / `mid` / `low` | 画质档位。默认电脑 mid、触屏设备 low；**电脑卡顿时用 `?q=low`**，显卡好可用 `?q=high` |

交互：拖动环顾（带惯性）、滚轮缩放视野、点击发光标记走近细看、底部滑杆调风力、「掀起一阵风」触发一道扫过全场的阵风、`Esc` 返回。

## 技术思路

纯前端，无构建步骤，仅依赖 `vendor/three.module.min.js`（Three.js r170）。

1. **由画作生成高斯笔触**（`src/generator.js`）
   - 读取画作像素，按「粗底色 → 中笔触 → 细笔触 → 边缘细节」四层采样，共约 10 万个各向异性高斯椭圆。
   - 每个椭圆的长轴沿局部笔触方向（图像结构张量），颜色带轻微的「色彩分割」抖动，所以静止时也像一幅在空间里展开的油画。
2. **深度与语义**（`src/scenes.js`）
   - 每幅画手工标注地平线、树线、人物、帆、房屋等分层；地面/水面用「眼高 + 地面平面投影」求深度。
   - 关键约束：**每个笔触只沿自己的视线滑动**，所以从原视点看，构图与原画逐像素一致。这是转场能无缝衔接 DOM 画作的原因。
3. **全景扩展**：画框之外的 300° 由程序生成——草地/河面、天空穹顶、树林带、农舍、额外的帆船与倒影。颜色全部从原画「同一深度带 / 同一仰角带」的像素中取样。
   - 画框边缘无缝：画内笔触在边缘逐渐稀疏溶解，扩展笔触越界进入画内；扩展笔触越靠近画框，颜色越多地取自画中最近的同类像素（天空取天空、水取水、岸取岸），所以看不到画框的边界。
   - 水面：只取原画中偏蓝的水色，叠加天空反射；倒影投影到水面上，画成水平的碎色块。
4. **调色**：每幅画有一组调色参数（`scenes.js` 中的 `grade`：伽马、曝光、白平衡、饱和度、提亮、对比度），去掉老照片的发黄发暗。转场时从原画色调渐变过去。
5. **渲染**（`src/splats.js`）
   - 实例化三角形 + 数据纹理，预乘 Alpha 从后往前混合。
   - 笔触是边缘清晰、带轻微不规则轮廓和笔刷纹的色块（而不是软高斯），粗底色层放在细笔触之后，避免互相盖成一片糊。
   - Web Worker 里做视锥剔除和 16 位基数排序（`src/sort.js`）。
   - 转场、风场、发光都在顶点着色器里完成：
     - 转场：笔触从画布平面沿视线飞到深度位置，途中有一道金色的展开波；扩展世界从画框边缘向外铺开。
     - 风场：沿风向传播的波 + 噪声阵风 + 可触发的阵风前沿。草被吹弯、沿风向拉长，浪尖提亮。
     - 发光与聚焦：热点笔触呼吸发光并带金色光晕；聚焦时其余部分降饱和、压暗。
6. **观赏界面与转场编排**（`src/main.js`）
   - 3D 相机的视锥与 DOM 中画作的屏幕矩形精确对齐（离轴投影）。动画过程中视锥插值回正常透视，并配合推镜。
   - 所有动画由同一个时钟驱动，所以既能实时运行，也能逐帧确定性录制。
7. 风声：WebAudio 实时合成，音量和音色随风力、阵风变化。

## 渲染演示视频（约 2 分钟）

`tools/render.mjs` 一条命令出成片：自带本地服务器，用本机 Chrome/Edge 逐帧播放自动演示（不受实时帧率影响，成片绝对流畅），ffmpeg 编码，并按画面里的风力合成风声音轨。

**准备**：安装 [Node.js](https://nodejs.org/)（18 或更新）和 Google Chrome（或 Edge）。

**运行**：
- Windows：双击 `render.bat`
- macOS：双击 `render.command`
- 或命令行：

```bash
cd monet-immersive
npm install                    # 首次：安装 puppeteer-core 与 ffmpeg（自动下载，无需单独安装）
node tools/render.mjs          # 1920x1080 · 30fps · 高画质 → monet_demo.mp4
```

渲染时会弹出一个浏览器窗口自动播放，**不要关闭它**（可以最小化到后面）。终端里会显示进度和预计剩余时间。有独立显卡的电脑一般十几分钟内完成。

| 参数 | 作用 |
|---|---|
| `--preview` | 快速预览：1280x720 · 24fps · 中画质 → `monet_demo_preview.mp4` |
| `--out 文件名.mp4` | 输出文件 |
| `--size 2560x1440` / `--fps 60` / `--q high\|mid\|low` | 分辨率、帧率、画质 |
| `--chrome "浏览器路径"` | 找不到浏览器时手动指定 |
| `--headless` | 不弹窗口（软件渲染，慢很多，适合服务器） |
| `--dry` | 只测量演示时长，不出视频 |

演示内容在 `src/demo.js`：罂粟花田（环顾、卡米耶与让、调高风力）→ 回到展厅 → 帆船赛（环顾、白帆、碎裂的倒影、阵风）→ 回到展厅。改其中的等待时间即可调整时长，改完用 `--dry` 查看总时长。

也可以打开 `http://localhost:8123/?demo` 直接录屏，但成片流畅度取决于电脑的实时帧率。

`node tools/capture.mjs --shots 10,20,30 --out shots` 可快速导出指定时间点的静帧。`--chrome` 可指定 Chrome 路径。

`node tools/shot.mjs --scene 1 --yaws 0,0.6,-0.6,3.1 --out shots` 进入指定画作后，按不同朝向（弧度）各截一张图，便于调色和检查画面。

## 目录

```
index.html / style.css        观赏界面、HUD、信息卡片
src/main.js                   状态机、转场编排、相机、交互
src/scenes.js                 两幅画的分层/深度/热点/导览文案
src/generator.js              画作 → 高斯笔触；全景扩展
src/splats.js                 高斯渲染着色器（转场、风、发光）与背景天穹
src/sort.js, sortWorker.js    视锥剔除 + 深度排序
src/demo.js                   自动演示脚本
src/audio.js                  实时风声
tools/                        render.mjs 视频渲染、shot.mjs 静帧检查、capture.mjs 逐帧导出、字体子集生成
assets/paintings/             画作（Wikimedia Commons，公有领域）
assets/fonts/                 思源宋体 / Cormorant Garamond 子集
```

## 后续可扩展

- 深度：用 Depth Anything 等单目深度估计替换手工分层，拉开近景视差。
- 资产：渲染层接口与 Spark（Three.js 3DGS 渲染器）对齐，可换成 World Labs Marble 等生成的真实 `.spz` 场景。
- MR / VR：接入 WebXR，把风改成手势挥动触发，热点改成凝视加捏合。
- 内容：每位艺术家只需新增一个 `scenes.js` 配置（分层、热点、文案）。
