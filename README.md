# 可视化清单

单文件清单网页：勾选核对、多清单目录、本地保存。跨设备同步只需在每台设备输入一次同步口令。

## 打开方式

1. **电脑**：浏览器直接打开 `index.html`。
2. **手机**：拷贝文件夹后用本地文件浏览器打开；或放到静态托管后用链接打开。
3. **对话中**：路径 `/workspace/checklist/index.html`，可让助手打开预览。

未配置同步时完全离线可用（数据在浏览器 `localStorage`）。

> 可选：把本目录托管到 **GitHub Pages**（同一仓库），手机/电脑共用一个 URL，再配合下方 Gist 同步勾选状态。本仓库不强制配置 Pages。

## 功能

- **目录**：左上角切换多份清单
- **勾选**：点卡片核对 / 取消；进度条「已核对 X / Y」
- 数量（如 `×1套`）、红色标签、分组色块
- 右上「⋯」：同步设置、立即同步、导出/导入、全部取消勾选、清除已完成
- **新建 / 改内容**：在对话里告诉助手（应用内不提供编辑表单）

## 同步（手机 ↔ 电脑）

每台设备打开页面 → 右上「⋯」→ **同步设置** → 输入一次同步口令 → **保存**。口令记在本机浏览器里，之后打开页面、点顶栏「刷新」、或从后台回到页面时会自动拉取；勾选后约 1 秒自动推送。

状态只有几句人话：「已同步」「离线，联网后自动同步」「口令不对」。口令错了或暂时没网，本地清单照常可勾，不会被清空。

以前在这台设备上保存过 Gist ID 或 Token 的，打开新页面时会自动清掉，并提示再输入一次口令。

云端仍是原来的私密 Gist。Token 和 Gist ID 只放在 Cloudflare Worker 上，网页不再接触它们。部署步骤见 `worker/DEPLOY.md`。

合并规则：清单取并集，用 tombstone / `deletedListIds` 同步删除；同一份清单内容取较新的 `updatedAt`，条目勾选取较新的 `u`。服务端合并，避免后保存的一端盖掉另一端。

## 导出 / 导入

「⋯」→ 导出当前 / 全部 JSON；导入可选合并或替换。

JSON 根结构：

```json
{
  "version": 2,
  "updatedAt": 0,
  "activeListId": "...",
  "lists": [
    {
      "id": "...",
      "name": "清单名",
      "updatedAt": 0,
      "groups": [
        {
          "id": "...",
          "name": "分组",
          "color": "#1e3a5f",
          "items": [
            { "id": "...", "text": "名称", "qty": "×1", "tag": "", "note": "", "checked": false }
          ]
        }
      ]
    }
  ]
}
```
